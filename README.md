# Smali Fox — Android Studio Source

هذا مشروع Android Studio حقيقي مكتوب بـKotlin، وهو إعادة تنفيذ مستقلة لواجهة Smali Fox والوظائف الأساسية الظاهرة في الـAPK الذي تم تحليله.

## الوظائف الحالية

يتيح التطبيق اختيار ملف APK من الجهاز، وقراءة ملفات `classes*.dex`، وعدّ ملفات DEX والنصوص، والبحث عن مؤشرات مرتبطة بالشراء والاشتراكات والدفع، ثم عرض النتائج في بطاقات داكنة قابلة للبحث والنسخ. الواجهة تدعم العربية وتستخدم لوحة الألوان المستخرجة من التطبيق الأصلي.

يحتوي محرك الفحص على بنك Premium من **٢٠٠٠ كلمة مفتاحية فريدة** لمؤشرات الشراء والفوترة والاشتراك والترخيص والوصول والميزات المدفوعة، وتظهر الكلمات المطابقة داخل تفاصيل كل نتيجة.

أثناء التشغيل يعرض التطبيق المرحلة الحالية، واسم ملف DEX الجاري فحصه، وعدد الدوال المفحوصة، وعدد دوال Boolean المكتشفة، وعدد النتائج المتاحة لحظيًا، وعدد كلمات Premium المستخدمة. المراحل هي: تجهيز الملف، فحص وتحليل DEX، ثم إكمال وعرض النتائج.

من شاشة تفاصيل أي دالة يمكن الضغط على **تحليل عبر DeepSeek**. يستخدم التطبيق نفس مسارات الاتصال الموجودة في الملف المرفق: إنشاء جلسة، جلب تحدي PoW، تشغيل ملف WASM لحلّه، ثم إرسال `x-ds-pow-response` إلى `https://chat.deepseek.com/api/v0/chat/completion`. يطلب التطبيق رمز Bearer من المستخدم ويحفظه محليًا فقط. يوجد ملف WASM نفسه داخل `app/src/main/assets/`، كما يوجد المرجع الأصلي في `tools/deepseek_reference/`.

## الفتح في Android Studio

افتح المجلد `smali-fox-rebuild` من خلال **File > Open**. استخدم JDK 21 أو أحدث، ثم نفّذ **Sync Project with Gradle Files**. يمكن تشغيل المشروع على جهاز Android أو Emulator مباشرة.

للبناء من الطرفية:

```bash
./gradlew assembleDebug
```

سينتج الملف داخل `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظة عن المصدر الأصلي

الـAPK الأصلي كان محميًا بغلاف Native وpayload محمّل ديناميكيًا، ولذلك لم يكن مصدره الأصلي قابلًا للاستخراج حرفيًا. هذا المشروع يعيد تنفيذ السلوك الظاهر بصورة مستقلة ولا ينسخ مكتبات الحماية أو الكود المحمي.
